# QATARINA Share Test Session

In order to allow teams to involve/include their clients and other teams in the
testng process. Qatarina will have the concept of sharing a test session via
a link. This will generate a unique link for each test session which will be
asssociated with an initially anonymous user role.

The idea is to enable testers to complete testing without going through rigorous
steps to login or navigate on the UI to find the test session they are assigned to.

Example link will be something like:

https://qatarina.nndi.cloud/t/some-unique-id/start

this should allow users to record results or comments against test-cases associated
with that test session. When a user first opens that link it must ask for their
name and position, this may be used to generate or update the generated account.

https://qatarina.nndi.cloud/t/some-unique-id/complete
